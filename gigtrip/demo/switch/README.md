# Example export files for the "switch" import

These are **made-up files in a typical layout**, written by us so the RoadOps and
Master Tour switch flow can be demonstrated and tested. They are not real exports
from either product: neither company publishes its column names. When a real
export arrives, drop it into the wizard; any column it doesn't recognise is
matched by hand with "Columns", and the header words can then be added to
`IMPORT_KINDS` in `gigtrip/mock/index.html`.
